# Pingo Support

Pingo is an iMessage-only multiplayer game collection.

## Opening Pingo

Open Apple Messages, enter an iMessage conversation, open the Messages apps/stickers interface, choose Pingo, and expand it to select a game.

## A turn looks stale

Open the newest Pingo message card in the conversation. Pingo uses match revisions and rejects older state so a stale message cannot replace a newer turn.

## Restore Purchases

Open the Pingo Store inside Messages and choose **Restore Purchases**. Restored access is based on verified StoreKit entitlements for the Apple ID currently using the device.

## Sea Battle

Sea Battle keeps each player's fleet coordinates in that device's Messages-extension sandbox. Continue that player's Sea Battle turns on the device where the fleet was created.

## Reporting a problem

Include:

- game name
- device model and iOS/iPadOS version
- whether Pingo was compact or expanded
- which player's turn it was
- whether you opened the newest Pingo card
- exact error text, if any

Do not send purchase credentials, Apple ID passwords, signing keys, or private conversation contents.
